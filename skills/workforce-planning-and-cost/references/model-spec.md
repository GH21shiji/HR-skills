# 人力规划模型规范

只在需要建立或检查具体预算模型时读取本文件。根据用户所在公司政策增删字段，不套用固定比例。

## 推荐数据表

### 1. 假设表

| 字段 | 示例说明 |
|---|---|
| 版本 | 基准、保守、进取或滚动预测月份 |
| 币种与汇率 | 写明汇率日期和来源 |
| 成本口径 | 是否含奖金、福利、税费、招聘费、股权成本 |
| 入离职计费规则 | 按日、按半月或按整月 |
| 涨薪和奖金规则 | 来自已批准政策，不自行假设为事实 |
| 社保福利规则 | 按地区和适用人群配置 |

### 2. 人员明细

建议字段：稳定员工 ID、组织、成本中心、岗位、职级、工作地、FTE、入职日、预计离职日、固定月薪、固定津贴、奖金目标、福利成本、雇主税费、长期激励会计成本、数据版本。

姓名不是唯一键；不需要展示姓名时使用员工 ID。

### 3. 招聘与岗位计划

建议字段：需求 ID、业务目标、岗位、数量、招聘类型、预计职级、预计成本、批准状态、期望到岗月、预计招聘周期、优先级、不招聘的影响、负责人。

### 4. 业务驱动表

记录收入、项目数、客户数、产量、工时、服务量或其他业务指标，并说明它如何转换为岗位工作量。

## 月度计算原则

- 现有人力成本从计划期首开始计算，到离职生效月按公司口径停止；
- 新增人员从预计到岗月开始计算，并单列到岗延迟风险；
- 奖金、福利、税费和长期激励分别计算，避免在总包和附加成本中重复；
- FTE 小于 1、外包和实习生采用单独口径；
- 调岗不应导致同一员工在两个成本中心重复计算；
- 所有手工覆盖值记录原因、操作者和日期。

## 建议指标

根据业务实际选择，避免为了完整而全部使用：

- 月末 HC、平均 FTE；
- 人力成本总额及预算偏差；
- 人力成本率；
- 人均收入、人均毛利或人均产出；
- 关键岗位缺口和预计空缺天数；
- 已批准未到岗成本；
- 招聘到岗偏差、离职偏差；
- 不同情景的现金消耗和可支持月份。

## 核对清单

- 人员明细合计等于组织汇总；
- 成本中心汇总等于公司总表；
- 期初在岗等于上期实际期末；
- 期末 HC = 期初 HC + 入职 + 转入 - 离职 - 转出；
- 本期预测与上期预测的差异有原因；
- 财务口径和 HR 口径的差异单独列示；
- 数字四舍五入只发生在展示层，不发生在底层计算。
