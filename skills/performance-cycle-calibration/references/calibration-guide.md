# 绩效校准执行指南

只在准备或运行正式绩效周期时读取本文件。

## 证据分级

1. **直接结果**：经过核对的业务、项目、客户或质量数据；
2. **过程证据**：评审记录、交付物、事故记录、反馈记录；
3. **多方观察**：不同角色对同一行为的具体描述；
4. **单方描述**：可作为线索，需要进一步验证；
5. **印象或标签**：不能单独支持重要决定。

评价材料至少说明：发生时间、工作背景、员工责任、采取行动、产生结果、证据来源和与评价标准的关系。

## 校准会前检查

- 参评范围、规则、尺度和例外已确认；
- 目标变化和资源变化已记录；
- 初评包含具体证据；
- 低等级和高等级案例有足够材料；
- 新员工、转岗、长假和更换主管人员有一致处理规则；
- 主管之间的评分分布差异已标出，但不以分布自动定人；
- 利益冲突和申诉路径已说明。

## 建议议程

1. 重申规则、保密和决定权限；
2. 查看整体分布及明显异常；
3. 先讨论边界案例和证据不足案例；
4. 比较相似岗位、责任范围和结果；
5. 记录决定、条件、反对意见和补充材料；
6. 检查潜在偏差和跨团队一致性；
7. 明确审批、反馈、复议和归档安排。

## 反馈提纲

1. 先说明结果和适用标准；
2. 讲具体事实与影响；
3. 听取员工理解和不同证据；
4. 说明做得好的部分和关键差距；
5. 约定下一周期目标、资源和检查时间；
6. 说明复议渠道并形成记录。

反馈不得包含未经验证的传闻、人格评价、与工作无关的信息或未获批准的承诺。

## PIP 前置检查

以下任一项不充分时，先补足管理和证据工作，并取得专业复核意见：

- 岗位职责和绩效标准在问题发生前已明确；
- 绩效差距有持续、具体、可验证的证据；
- 员工此前收到及时反馈，而非最终结果时首次得知；
- 资源、权限、培训和合理支持没有明显缺失；
- 计划目标可达到、可衡量且有明确期限；
- 主管能按周期提供反馈和记录；
- 公司制度、合同和适用地区要求已检查；
- 决策不基于报复、歧视或其他不当原因。

AI 只准备材料和检查缺口，不判断 PIP 是否具有法律效力。
