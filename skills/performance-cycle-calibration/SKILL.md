# 绩效周期与校准会议

绩效管理的最低要求是标准提前明确、评价基于证据、结果经过适当比较、员工不会在最终沟通时第一次听到问题。

## 不可越过的边界

- AI 可以整理材料、发现证据缺口和模拟会议，不能自主决定绩效等级、奖金、晋升、PIP 或解除劳动关系。
- 不根据受保护特征、私人关系、传闻或与工作无关的信息评价员工。
- 不为满足分布比例而编造证据或强行降低个人等级。
- 涉及 PIP、试用期不通过或解除时，必须检查适用地区制度、证据和专业复核要求。
- 未经授权，不向员工发送结果或写回正式系统。

## 工作流程

1. **确定周期规则**：记录适用人群、时间范围、评价尺度、角色、例外、申诉和审批方式。
2. **检查目标质量**：目标应明确预期结果、衡量方式、权重、依赖条件和期间发生的重大变化。
3. **收集评价材料**：员工自评、项目结果、协作者反馈、主管评价和必要的业务数据。
4. **执行证据检查**：区分可验证结果、行为事实、解释、传闻和缺失信息；提示不充分评价。
5. **准备校准会议**：生成分布概览、边界案例、跨团队可比项、需要讨论的问题和利益冲突提示。
6. **主持或辅助校准**：逐案记录事实、标准、争议、决定、条件和负责人；不能用声音大小代替证据。
7. **检查公平性**：比较相似岗位和相似责任，检查标准漂移、近因偏差、光环效应和主管宽严差异。
8. **准备结果沟通**：主管讲清结果、证据、期望差距、下一周期目标和支持措施。
9. **处理复议或 PIP 前置**：整理争议点和证据缺口；只有在标准、反馈、支持和记录充分时才进入正式程序。
10. **归档与复盘**：保留审批、版本和反馈记录，复盘流程时长、证据质量和争议原因。

会议议程、证据分级、反馈提纲和 PIP 前置清单见 [references/calibration-guide.md](references/calibration-guide.md)。

## 输出

- 绩效周期日历和责任表；
- 材料完整性与证据质量检查；
- 校准会议议程和边界案例清单；
- 决定记录及待办；
- 主管反馈提纲；
- PIP 或劳动风险的专业复核提示。
